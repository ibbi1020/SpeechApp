Why the wave does not go full screen

The pill is a 1-D heightfield clipped to a capsule about 132 points wide. Two listening crests fill that width. Spread across a phone, the same shape is either a stranded pair of hills or a row of spikes on a blue bar. Gemini ran the same experiment in public and retreated: Live used to be a full-screen waveform, and the current UI is a pill, with a floating orb only when you leave the conversation. ChatGPT's full-screen voice screen is an orb, which stays round when the phone gets wider. The pattern that is drawn at screen size, rather than scaled up from a small widget, is an edge glow.

Prototype: edge glow

The phones above borrow the Apple Intelligence / Siri grammar: lobes of light travel the rounded bezel, and the center is punched out so type stays readable. Palette is this lab's ice, electric blue, violet, and bottle green. It is a canvas approximation (conic stroke plus radial lobes), not Apple's shader and not a Siri impersonation. Listening is dim and slow, connecting is a steady drift, speaking is brighter and faster. Mic energy thickens it. Reduce Motion holds one frame.

What the recording actually is

Not a waveform, not a 3D orb, not overlapping blobs. A capsule on black whose fill is a 1-D heightfield. Listening is two slow crests. Connecting is a steady ripple traveling left to right. While the AI is speaking the horizon breaks into three faster peaks with deep troughs between them, and the tall ones pick up magenta and bottle green. Sampled from your Gemini Live recording (the visualizer itself is proprietary — Gemini said so in the same clip).

Swift practice (iOS 18+ MeshGradient)

Pixel-match to this lab: TimelineView(.animation) + Canvas drawing the same heightfield. GPU-cheap cousin: a 4×3 MeshGradient in a Capsule — top row near-black and pinned, middle row is the ice ridge (only interior points move), bottom row electric blue and pinned. Never mutate grid size (Metal recompiles). smoothsColors: true, colorSpace: .perceptual, background: .black. Animate points, not hues. Energy is fast attack / slow release so the ridge doesn’t chatter. Reduce Motion freezes on a static dim glow.

Edge glow

The family the prototype belongs to. Light on the boundary, content in the middle. Width is the design.

  • Apple Intelligence edge glow, explained. System UI, no public API. Stacked angular strokes, a soft bloom, hue motion. State lamp: hot while listening, slower while thinking, gone when idle.
  • christopherkarani/aurora. SwiftUI + Metal. The practical port: anchored metaballs and a noise-warped SDF around the screen, .subtle / .standard / .dramatic. This is the iOS path if the prototype holds.

Centered orb

Full screen because the empty field around a circle is intentional. The orb does not stretch. It does cover the middle, which fights a reading passage.

  • ChatGPT Advanced Voice. Blue-white orb, audio-reactive, optional separate full-screen mode.
  • Gemini Live, before the pill. Full-screen animated gradient. Google has since shrunk it.
  • ElevenLabs Orb and Swift OrbVisualizer. Three.js / SwiftUI orb with listening, thinking, talking. The production state machine to copy, not the silhouette.
  • orb-ui themes. One React orb, themes circle, cloud, radial, bars. Adapters for Vapi, ElevenLabs, LiveKit, Pipecat, OpenAI Realtime, Gemini Live.
  • Murmur and Murmur for the web. 18 Metal glass species, including .aura, designed at 120 pt, 46 pt, and 18 pt. Steal level + activity, not a species, unless the presence is an orb.
  • metasidd/Orb. Particle orb. A round agent face, not a screen.

Shader aura

A bounded ellipse you can make large. Still a widget. Scaling it up is the same trap as scaling the pill.

  • LiveKit AgentAudioVisualizerAura. Unicorn Studio shader, sizes icon through xl, state plus volume. The reputable component kit.
  • LiveKit custom shader guide. How that aura is built, if you fork the GLSL.
  • Unicorn Studio. The shader author LiveKit partnered with.
  • AgentSessionView. Full session chrome (transcript, controls) with a swappable visualizer. The layout, not the light.

Bars, waves, grids

Honest at pill size. They are the family this page already is. Do not expand them.

  • LiveKit bar, grid, radial, wave. Same props as Aura. Swift ships AgentBarAudioVisualizer only.
  • ElevenLabs BarVisualizer. Frequency bars with the same agent states as the orb.
  • Gemini's pill. The full-screen waveform, condensed. This lab's capsule is the local version of that decision.

Providers that borrow a face
